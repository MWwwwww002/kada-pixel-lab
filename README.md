# KADA Pixel Lab

咔哒 · KADA 的像素表情制作器。用 80 × 60 的 4:3 像素画布绘制屏幕表情，支持导出透明 PNG。

## 开始使用

下载 [`index.html`](./index.html)，用浏览器打开即可。网页使用原生 HTML、CSS 和 JavaScript，无需安装依赖、启动服务或联网。

## 功能

- 使用画笔和橡皮擦编辑像素，支持左右对称绘制和擦除。
- 从 17 种表情预设开始，也可以清空画布自由绘制。
- 调整笔刷大小、像素点大小、颜色和发光强度。
- 支持撤销和重做。撤销使用 `Ctrl/⌘ + Z`，重做使用 `Ctrl/⌘ + Shift + Z` 或 `Ctrl/⌘ + Y`。
- 导出 2880 × 2160 的透明 PNG。浏览器允许访问剪贴板时，也可以直接复制 PNG。
