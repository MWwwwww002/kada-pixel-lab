# KADA Pixel Lab

一款轻量的像素表情绘制工具。通过画笔、对称绘制和表情预设，快速制作像素风眼睛、屏幕表情和简单图案。完成后可导出透明 PNG，方便用于角色设计、插画、视觉方案等创作场景。

**[在线使用 KADA Pixel Lab](https://mwwwwww002.github.io/kada-pixel-lab/)**

## 功能特点

- **像素画布** · 80 × 60 网格，4:3 比例，适合绘制屏幕表情和像素图案。
- **自由绘制** · 使用画笔和橡皮擦调整细节，支持 1 × 1 至 5 × 5 的笔刷大小。
- **左右对称** · 开启镜像同步后，绘制和擦除都会同步到画布另一侧，方便制作对称表情。
- **17 种表情预设** · 包含开心、困倦、心动、暴怒、坏笑及游戏状态等，可作为绘制起点继续编辑。
- **外观调整** · 可选择预设颜色或自定义颜色，调整像素点大小与发光强度。
- **透明 PNG** · 支持导出 2880 × 2160 的透明图片，也可在浏览器支持时直接复制 PNG。
- **撤销和重做** · 支持按钮和快捷键，方便调整绘制过程。

## 使用方法

1. 打开[在线工具](https://mwwwwww002.github.io/kada-pixel-lab/)，选择表情预设，或直接在画布上绘制。
2. 使用画笔、橡皮擦与左右镜像调整图案。按住鼠标拖动可以连续绘制，右键拖动可临时擦除。
3. 根据需要调整笔刷、像素点大小、颜色和发光强度。
4. 点击「导出透明 PNG」保存图片，或点击「复制 PNG」粘贴到支持的应用中。

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl + Z`（Windows）/ `⌘ + Z`（Mac） |
| 重做 | `Ctrl + Shift + Z` 或 `Ctrl + Y`（Windows）/ `⌘ + Shift + Z` 或 `⌘ + Y`（Mac） |

## 本地使用

下载 [`index.html`](./index.html)，用浏览器打开即可。工具使用原生 HTML、CSS 和 JavaScript 编写，无需安装依赖或启动服务。

复制 PNG 功能取决于浏览器的剪贴板支持和权限，无法复制时可以使用「导出透明 PNG」。
